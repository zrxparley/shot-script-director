# 🎬 Shot Script Director - 自媒体镜头脚本AI顾问

> **V6 | 40条约束 | 6位导演三测平均 9.9/10**

输入自然语言描述，输出完整镜头脚本、拉片策划、拍摄建议、AI生图Prompt。支持6种导演风格混配、非线性叙事、场面调度、复盘分析。

---

## 🎯 解决什么问题

自媒体创作者最难的不是拍，而是**拍之前**：
- 想法在脑子里，但不知道怎么拆成镜头
- 知道想要"电影感"，但不知道具体怎么拍
- 看了大师作品，但拉片后还是不会用

**Shot Script Director** 把"导演的脑子"做成了一套结构化流程：你说想法，它出脚本。

## 🎭 6种导演风格

| 风格 | 适合场景 | 特征 |
|------|---------|------|
| **Casey Neistat 式** | 日常vlog/快节奏生活 | 手持快切1-3s/画外音驱动/BGM beat同步/废片预留 |
| **Peter McKinnon 式** | 产品/质感/电影感 | 稳定器2-5s/B-roll 70%/曝光三角+ND连锁重算+多LUT |
| **是枝裕和式** | 家庭/生活/时间流逝 | 固定机位5-15s/留白镜头/等待指令/转场实现方式/不拍清单 |
| **王家卫式** | 情感/城市/记忆 | 步抽帧+慢动作/4时间层/色彩参数/虚焦/倾斜角度/构图呼应/帧率混合/独白语言 |
| **纪录片式** | 家庭记录/真实场景 | 框架模式(非指令)/退后一步提醒/声音肖像/空镜头/不在场拍摄/被拍摄者剪辑权/不在了预案 |
| **One Shot 式** | 连续叙事/空间穿越 | 阶梯平面图/EV测量/设备切换/呼吸点/NG预案/排练+体力预估/便携收音 |

## 📐 工作流程（13步）

```
Step 1  → 意图理解与风格推荐
Step 2  → 镜头脚本生成（基础表 + 风格专属扩展列 + 情绪弧线 + 分段混配 + 时长双策略校验 + 空间平面图 + 不拍清单）
Step 3  → 专属模块输出（画外音/B-roll/物件象征/环境音轨/声音肖像/场面调度/拍摄框架/不在场拍摄/转场实现/虚焦/独白语言/构图呼应/帧率混合/年度递进）
Step 4  → BGM/BPM推荐（含免版权音源+BPM过渡+beat同步）
Step 5  → 曝光三角+ND连锁重算（含无ND替代+EV测量）
Step 6  → 色彩调色参数量化+多LUT分段
Step 7  → 便携收音方案（含开拍前测试录音）
Step 8  → 拉片策划
Step 9  → 拍摄建议（含开拍前设备检查清单+水平自适应）
Step 10 → AI生图Prompt（双语）
Step 11 → 复盘模块
Step 12 → 系列化规划（可选）
Step 13 → 伦理提示（涉及真人自动触发）
```

## 🚀 使用方式

### 输入示例
> "拍一个早晨喝咖啡的vlog，大概1分钟，在家里拍，用手就行不想买设备"

### 输出（摘要）
- **风格推荐**：Casey Neistat 式（手持快切，适合手机拍摄）
- **镜头脚本**：15个镜头，从起床到喝完咖啡，每个1-3秒
- **拉片策划**：Casey Neistat "Morning Routine" 逐镜分析
- **拍摄建议**：手机+自然光，先拍B-roll再拍主线
- **AI生图Prompt**：一张分镜全景图，展示15个咖啡早晨画面
- **BGM推荐**：90BPM lo-fi hip hop + YouTube Audio Library搜索关键词
- **复盘模块**：拍完后对比计划vs实际

## 📋 40条约束速览

### 通用约束（13条）
不编造参考作品 / 景别标注 / 时长到秒 / 双策略校验 / 双语Prompt / 情绪弧线 / 设备分级 / 风格混配 / 参数具体化 / 转场具体化 / 水平自适应 / 设备检查清单 / 伦理提示

### Casey Neistat 专属（3条）
节奏波形 / 转场动作设计 / 画外音(含情绪强度1-5+笑/叹气) / BGM+BPM+beat同步

### Peter McKinnon 专属（4条）
曝光三角 / 对焦距离预警 / ND连锁重算+无ND替代 / B-roll(含ND+曝光) / 多LUT分段

### 是枝裕和专属（6条）
留白镜头 / 等待指令 / 转场时长 / 转场实现方式(前期vs后期+声音桥+直切语义) / 不拍清单 / 季节感

### 王家卫专属（8条）
4时间层 / 色彩滤镜+倾斜角度 / 色彩调色参数量化 / 虚焦参数量化 / 独白语言选项 / 构图呼应 / 帧率混合效果 / 重复构图呼应

### 纪录片专属（6条）
拍摄框架模式 / 退后一步提醒(每30min) / 空镜头框架 / 声音肖像+录制时间轴 / 不在场拍摄+被拍摄者剪辑权 / 年度递进+不在了预案

### One Shot 专属（6条）
阶梯平面图(╱╱╱/╲╲╲+剖面图) / EV值测量 / 呼吸点 / 设备切换 / 便携收音+测试 / 排练+体力预估

## 🔮 V7 Roadmap（19项候选）

### 平台适配类（高优先级）
- [ ] 手机LUT实现方式（CapCut/剪映/Dazz Cam）
- [ ] 手机拍摄模式建议（人像/夜景/慢动作）
- [ ] 手机防抖模式开关建议
- [ ] 手机曝光锁定建议
- [ ] 日落时间窗反推出发时间

### 调色深度类（中优先级）
- [ ] 统一调色基底（暗部/高光统一+分段LUT叠加）
- [ ] 低光补光方案（LED补光面板建议）
- [ ] 季节性LUT温度偏移（春天+200K/冬天-200K）

### 王家卫式深度类（中优先级）
- [ ] 焦点呼吸效果（清晰→虚→清晰动态虚焦）
- [ ] "沉默即语言"标注（哪些镜头不该有独白）
- [ ] 反向构图呼应（从平衡到微失衡=接受但仍有波动）

### 纪录片伦理深度类（低优先级）
- [ ] 生前声音录制建议（家族记忆vs纪录片素材）
- [ ] "不在了"预案增加家族共识
- [ ] 替代拍摄对象（传承线：妈妈学奶奶腌菜）

### 细节打磨类（低优先级）
- [ ] B-roll收音建议（同步vs后期配）
- [ ] 是枝裕和式直切使用边界
- [ ] 帧率混合修正不牺牲叙事功能
- [ ] 剖面图台阶数量标注
- [ ] EV测量增加过渡段时间窗计算
