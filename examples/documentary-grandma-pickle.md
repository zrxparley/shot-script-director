# 示例3：纪录片式 - 奶奶腌咸菜的下午

> **输入：** "拍奶奶腌咸菜的下午，奶奶80岁了，手很巧但今年身体不如去年了"

## 风格推荐：纪录片式（《四个春天》风格）

理由：家庭纪实+时间流逝感+高龄被拍摄者，需要伦理框架和年度递进设计。

---

## 拍摄框架

```
拍摄时段：下午1点-4点（3小时窗口）
拍摄对象：奶奶在院子里腌咸菜
拍摄目标：捕捉"80岁的手与蔬菜"的日常质感
不干预原则：不喊action，不要求重做，如果她讲过去的事不打断
预计素材时长：3小时（最终剪出2分钟）
素材-成片比：约90:1

关键瞬间预判：
- 奶奶洗菜时手在水中搓揉 -> 手部特写
- 奶奶撒盐时手微微发抖 -> 不靠近，远景记录
- 奶奶停下来歇息看远处 -> 中景人物状态
- 奶奶哼起老歌 -> 靠近拍侧面
- 奶奶说"今年手不太听使唤了" -> 不要特写颤抖，拍侧脸
```

## "不拍什么"清单

```
❌ 不拍奶奶面部大特写（破坏距离感）
❌ 不拍手抖的特写（尊严比纪录片重要）
❌ 不用变焦推拉
❌ 留白镜头(S3/S6/S9)不加画外音或配乐
❌ 不配BGM
❌ 不摆拍
❌ 不加速/延时
❌ 奶奶说"别拍了"->立刻关机
❌ 邻居来串门->移开镜头
```

## 声音肖像（含录制时间轴）

| 录制号 | 声音内容 | 录制方式 | 时长 | 用途 |
|--------|---------|---------|------|------|
| A1 | 洗菜搓揉声 | 指向性麦靠近 | 60s | 动作声音特写 |
| A2 | 撒盐声"沙沙" | 接触式麦贴缸壁 | 60s | 盐与缸的对话 |
| A3 | 奶奶哼老歌 | 领夹麦 | 等待 | 人物声音印记 |
| A4 | 院子环境声 | 录音机固定 | 120s | 空间底噪 |
| A5 | 奶奶说"今年手不太听使唤了" | 领夹麦 | 等待 | 时间的声音 |
| A6 | 奶奶离开后院子安静 | 录音机固定 | 60s | "人不在场的在" |

时间轴：13:00环境底噪 -> 13:10搓菜/撒盐 -> 14:00休息 -> 14:30第二段 -> 14:40奶奶走后独录

## 年度递进计划（含"不在了"预案）

**第1年（今年）：** 全景固定+手部特写+空镜+声音肖像
**第2年：** 增加面部中景+完整工序+奶奶讲述画外音
**第3年：** 拍成品使用场景（年夜饭）+奶奶教孙女腌菜（传承）
**第4年：** 同机位同时间对比第1年
**第5年：** 5年素材剪20分钟，名字《咸菜》或《奶奶的手》

### "拍摄对象不在了"预案

| 情况 | 应对方案 |
|------|---------|
| 身体不适 | 改拍物件和空镜，不拍人，录环境音 |
| 住院 | 带录音笔录对话(不拍)，拍空病床和窗台 |
| 手抖加重 | 不拍颤抖特写，改为远景或拍背影/手部侧面 |
| 离世 | 停止拍摄。用已有素材完成影片。不在葬礼上拍。 |
| 离世后第一年 | 拍空院子/空缸/旧菜板/空椅子，录"不在场的在" |
| 离世后第二年 | 整理5年素材开始剪辑。不急着发布。 |

**核心原则：**
- 影片永远不如人重要
- 如果奶奶说"今年做不了了"，那今年就拍她说这句话
- 如果奶奶离世，影片结尾应该是"空"——空院子、空缸、空椅子
- 最后一行字幕："献给奶奶，以及她缸里的咸菜味"

---

## 被拍摄者剪辑权

1. 拍完后用手机放几个关键段落给奶奶看
2. 问"奶奶，这些能给别人看吗？"
3. 她说"行"就行，她说"这个不好看别放"就不放
4. 她的回答是最终决定

---

## 今年的特殊建议

- 奶奶80岁且身体不如去年，今年可能需要启动预案第一阶段
- 建议今年多拍空镜和声音肖像，减少对奶奶的长时间拍摄
- 如果奶奶只能做30分钟就累了，30分钟足够了
- 把"奶奶今年做不了那么多了"也拍进去——这本身是时间的故事
